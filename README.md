# Smart Pantry Manager (Android, Java)

This is a Java + XML Android app scaffold for the university assignment "Smart Pantry Manager". It uses SQLiteOpenHelper, RecyclerView, Activities, Intents and plain Java.

Open the folder in Android Studio and run the app on an emulator/device.

Structure highlights:
- `app/src/main/java/com/example/smartpantry/` - Java source
- `app/src/main/res/layout/` - XML layouts
- SQLite DB implemented in `DBHelper.java`
